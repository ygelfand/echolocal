The gear in the dock opens **Settings**. Every setting here is also an entity on the device in
Home Assistant unless the table says otherwise, and a change in either place shows up in the other.
Settings that only exist in Home Assistant are on [Settings in Home Assistant](/use/entities/).

<Aside>
The Echo Dot has no screen. Everything on this page that it supports is in Home Assistant and on
the [EchoLocal card](/start/integration/); see [Settings in Home Assistant](/use/entities/).
</Aside>

The **Entity** column is the entity id Home Assistant gives it by default, with `<device>` standing for
your device's name. "—" means the setting is only on the screen.

## Finding a setting

Tap **Search settings** in the header of any Settings page and type a word from a setting's name
or description. Results include individual controls and pages, with their location in the menu.
Tap a result to open its page and scroll to the control.

The search field stays in the header as you navigate. Its query is remembered when you leave a
page or close and reopen Settings, until the device restarts. Clear the field to browse the
page normally. Search does not match saved values or passwords.

## Typing with a phone

Open a text field on the device, then tap the QR-code button on its on-screen keyboard.
Scan the code with a phone on the same network. Type in the phone's browser; edits appear in the
field on the device. Choose **Save** to finish or **Cancel** to cancel the edit.

The code is reusable for two minutes, and each paired browser has a 15-minute session. Access is
limited to that field: closing it or opening a different field ends access to the old one. It does
not grant screen control or admin access. If the field changes elsewhere, reload before editing;
if access ends, open the keyboard's QR code again and pair with the current field.

The phone opens the device's local HTTPS address. See
[The certificate](/use/web/#the-certificate) for browser certificate warnings; no admin password is needed
for this paired field.

### Settings Lock

**Set PIN** asks for a new PIN twice. Once it's set, the page offers **Change PIN** and **Remove
PIN**. After five wrong tries, the next try has to wait 30 seconds, and the wait doubles with every
wrong try after that, up to an hour.

The PIN can also be set from Home Assistant with **Settings Lock**; clearing it there removes the
lock.
