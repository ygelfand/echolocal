title: Settings in Home Assistant
description: Settings in Home Assistant, including those not on the screen, plus sensors, buttons, events and actions.

Most settings on [Settings on the screen](/use/settings/) are also Home Assistant entities; that
page marks screen-only controls. This page
covers additional settings, including the microphones, the assistants' timing and ducking, plus
the sensors, buttons, events and actions. It also points to [photo settings](/features/photos/),
which are available on the screen too. Settings are also available in the device's
[web page](/use/web/).

Find them on the device's page under **Settings → Devices & services → ESPHome**. The
**Entity** column is the entity id Home Assistant gives each one by default, with `<device>` standing
for your device's name.

The entities are grouped into sub-devices: **ring**,
**microphone**, **playback**, **screen**, **camera**, **dashboard**, **voice triggers**,
**assistant 1** and **assistant 2**, each named after your device. The [EchoLocal card](/start/integration/) shows the
same settings grouped the same way, with a **?** next to each that explains it.

## Speaker

| Entity | Name | What it does | Range | Default |
|---|---|---|---|---|
| `media_player.<device>_speaker` | Speaker | The media player: announcements, TTS, music, volume | | |
| `number.<device>_playback_music_ducking` | Music ducking | How far music drops while the assistant listens or talks | −40 to −3 dB | −15 dB |
| `select.<device>_playback_white_noise_layer_1`, `select.<device>_playback_white_noise_layer_2` | White noise layer 1, 2 | Two layers of steady sound, mixed, ducking under everything else | None, White, Pink, Brown, Rain, Ocean, Brook, Wind, Fire, Crickets, Fan, Cabin | None |
| `switch.<device>_playback_speaker_eq` | Speaker EQ | Amazon's own EQ and limiter for this speaker, adjusted with the volume. Turn it off to hear the speaker flat | On, Off | On |
| `select.<device>_playback_voice_resampling` | Voice resampling | How assistant replies are converted to the speaker's rate | Band limited, Linear, Repeat samples | Band limited |
| `select.<device>_playback_speaker` | Speaker | Whether the built-in speaker plays. **Auto**: only while nothing is plugged into the headphone jack | Auto, On, Off | Auto |
| `select.<device>_playback_headphone_jack` | Headphone jack | Whether the headphone jack plays. **Auto**: only while something is plugged in | Auto, On, Off | Auto |
| `volume_*` | Volumes | The same sliders as Settings → Sound | 0–100 % | |

The Echo Show 8 (1st gen, crown) and Echo Show 8 (2nd gen, athena) play in stereo; the other
supported Echos play mono. **Speaker** and **Headphone jack** are available on devices with a
headphone jack: the Echo Dot (2nd gen, biscuit), Echo Show 5 (1st gen, checkers) and Echo Show 8
(1st gen, crown).

## Voice assistants

Each assistant has its own set, on its own sub-device. `N` is 1 or 2.

| Entity | Name | What it does | Range | Default |
|---|---|---|---|---|
| `button.<device>_assistant_N_wake` | Wake | Start this assistant without the wake word (button) | | |
| `number.<device>_assistant_N_wake_word_sensitivity` | Wake word sensitivity | Higher needs a clearer wake word | 0.5–0.99 | 0.85 |
| `select.<device>_assistant_N_wake_word_tone` | Wake word tone | The sound when it wakes | Chimes, custom tones | Chirp |
| `select.<device>_assistant_N_reply_delivery` | Reply delivery | Download the reply first, or stream it | Download first, Stream | Download first |
| `number.<device>_assistant_N_reply_buffer` | Reply buffer | How much of a streamed reply to collect before playing | 0–3000 ms | 650 ms |
| `number.<device>_assistant_N_follow_up_time` | Follow-up time | Keep listening this long after a reply, for another request without the wake word | 0–30 s | 0 |
| `number.<device>_assistant_N_max_listening_time` | Max listening time | Stop listening after this long | 5–60 s | 15 s |
| `number.<device>_assistant_N_max_thinking_time` | Max thinking time | Give up waiting for Home Assistant after this long | 5–300 s | 90 s |
| `number.<device>_assistant_N_recordings_kept` | Recordings kept | Keep the last N requests' audio, for the `recordings` action and the card's Activity tab | 0–10 | 0 |

The wake word and the Assist pipeline are picked with Home Assistant's own selects on the same
device.

| Entity | Name | What it does | Range | Default |
|---|---|---|---|---|
| `number.<device>_microphone_stop_word_sensitivity` | Stop word sensitivity | How sure "Stop" has to be. 1 turns it off | 0.5–1 | 0.7 |
| `sensor.<device>_last_wake_word`, `sensor.<device>_last_heard`, `sensor.<device>_last_reply` | | The last wake word, what was heard, and the reply (sensors) | | |
| `sensor.<device>_timers` | Timers | Running timers (sensor) | | |

## Sensors

IP address, board and color, free space, Wi‑Fi signal and traffic, Bluetooth advertisements per
second, CPU and radio temperature, CPU cores, load average, available memory, the room's sound level
and noise floor, light level, headphones plugged in, now playing and artist, the call state and who
it's with, the Sendspin state, and the Cast credentials' expiry.

## Events

| Event | When |
|---|---|
| `button_action`, `button_mute`, `button_volume_up`, `button_volume_down` | A button is pressed or held (event types `press` and `hold`; the action button also `double` and `triple`), so you can use the buttons in automations |
| `update_outcome` | An update finished or failed |
| `esphome.alarm_ringing`, `esphome.alarm_snoozed`, `esphome.alarm_stopped` | An [alarm](/features/messages/#alarms) rings, is snoozed or stopped |
| `esphome.screen_alert` | A Tessera alert was dismissed or a button on it tapped (action, title, screen) |
| `esphome.echolocal_turn` | An assistant turn finished, with its timings |
| `esphome.echolocal_duck` | The device lowered its media for an assistant turn, or brought it back (`ducked`, `duck_db`) |

## Actions

Call these as `esphome.<device>_<action>`, for example `esphome.kitchen_show_message`.

| Action | What it does |
|---|---|
| `show_message`, `clear_message` | Show or clear a [message](/features/messages/) (Echo Show) |
| `call` | Call another device by name (`peer`), with `video: true` for a video call ([Intercom](/features/intercom/#calling-by-voice)) |
| `broadcast` | Play an audio file (`message`, its URL) on every other device in this home ([Broadcasts](/features/intercom/#broadcasts)) |
| `alarm_list`, `alarm_set`, `alarm_enable`, `alarm_delete`, `alarm_stop`, `alarm_snooze` | [Alarms](/features/messages/#alarms) |
| `tone_write`, `tone_rename`, `tone_remove` | [Custom tones](/features/tones/) |
| `recordings`, `turn_audio` | The kept recordings of recent requests |
| `settings_export` | Every setting that can be copied to another device, with its section, title and value |
| `settings_import` | Apply settings from another device: `settings` is JSON of domain → setting → value, the shape `settings_export` lists. Answers how many changed and which were skipped |
| `logs` | The device's recent log |
| `<orientation>_show_page`, `_show_alert`, `_show_alert_choice`, `_dismiss_alert`, `_screen_message` | [Tessera](/use/dashboards/#tessera) pages and alerts |

Picking a wake word on the screen requires **Allow the device to perform Home Assistant actions**
in the device's ESPHome integration options.
