## From Home Assistant

New versions show up under **Settings → Updates** through the device's **Firmware** entity.
Install from there, or press **Check for updates** to look now.

On the Echo Dot, use Home Assistant or the [ADB commands below](#from-adb).

## From the screen

On the Echo Shows,
**Settings → System → Software update** shows the current version, **Check for updates**, and
**Download and install** when an update is available.

## Without internet access

A device kept off the internet can get its updates through Home Assistant. Turn on **Download
through Home Assistant** (`network_via_home`) under **Settings → Network & internet**, on the screen
or in Home Assistant. It needs the [EchoLocal integration](/start/integration/) and **Allow the
device to perform Home Assistant actions** in the device's ESPHome integration options.

Updates, the cast engine, speech models and wake word packs then download through Home Assistant,
which fetches them from GitHub and the release file host only. Photos, radar and other
downloads still go directly.

## Checks

The device checks for updates a few minutes after startup, then daily. **Update status** shows
progress, and **Update outcome** fires when an update finishes or fails.

## Update channel

**Update channel** (`update_channel`), on the screen or in Home Assistant:

- **Stable** (`stable`): releases
- **Development** (`dev`): the latest builds, for trying fixes early

Only newer builds are offered.

## Other versions

To go back to an earlier version, or try a particular one, install it by name. The list holds the
ten latest releases and the ten latest development builds, leaving out any without a build for this
device.

- **In Home Assistant:** pick it in **Install version**, then press **Install selected version**.
- **On the screen:** **Settings → System → Software update → Other versions**, then tap a version
  and confirm.

EchoLocal restarts on the version you picked.

## From ADB

With ADB connected, list releases for the device or install a particular release tag:

```sh
adb -s <serial> shell echod ctl firmware list
adb -s <serial> shell echod ctl firmware install <version>
```

Use the exact version tag. Older releases can be installed without changing the update channel.
Installing restarts the device; the control connection may close during restart. Check the
running version after it returns:

```sh
adb -s <serial> shell echod ctl device version
```

These commands need a running echod and network access to download the release. They do not
need the screen or Home Assistant. If the daemon cannot start, reinstall through the host CLI.
