## Echo Dot (2nd gen, biscuit)

No screen: a twelve-segment light ring, four buttons and a seven-microphone array. Change its settings
in [a browser](/use/web/), in Home Assistant or on the [EchoLocal card](/start/integration/#the-card). See
[Echo Dot: buttons and light ring](/use/dot/).

## Echo (2nd gen, radar)

Experimental. The same platform as the Echo Dot (2nd gen) in a larger speaker, so it runs the same
build and behaves the same way: see [Echo Dot: buttons and light ring](/use/dot/). It has had far
less testing than the Dot.

## Echo Show 5 (1st gen, checkers)

A 5.5-inch, 960 × 480 touchscreen, camera and mono speaker.

## Echo Show 5 (2nd gen, cronos)

The same screen size and resolution as checkers, with a camera and mono speaker. This generation
comes with two different speaker amplifiers; EchoLocal handles both.

## Echo Show 8 (1st gen, crown)

A bigger screen, a larger dashboard grid, and stereo speakers.

## Echo Show 8 (2nd gen, athena)

The same screen and stereo speakers as the first generation. Its camera goes up to 1920 × 1080 and
is the only Echo camera with a [sub stream](/features/camera/#rtsp).

<Aside type="note">
Other Echos aren't supported yet.
